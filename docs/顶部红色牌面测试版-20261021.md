# 顶部红色牌面测试版（2026-10-21）

昨天最后一轮实验 `1792491903744-5354` 的第 788 帧，在限速牌从画面顶部进入、AI 还没有检测框时，圆环底部被二值几何规则当成道路分隔带，产生了一帧 `FORK_WAIT`。这属于正常摆牌输入需要处理的问题。

本版在同帧彩色图中寻找与二值暗区对应的、触顶、扁平且主体明确偏红的独立连通域。只有原几何结果将判为分叉时才执行该补充检查，并仅在比赛几何使用的副本中还原该连通域像素。巡线二值图、边界、速度配置及 AI 类别映射保持原样。不扩大外接矩形、不填补整段顶部、不沿用历史检测框，也不统一延迟未知岔路停车。

此补充检查只提供“该区域有明确红色物体证据”的排除依据，不代表识别出了限速牌，也不取代神经网络识别和交通任务确认。停止、限速和解除限速仍由原 AI 确认及状态机处理。彩色图缺失、尺寸不符、颜色证据不足或暗色区域连接着较长的黑色分隔带时，保留原几何判断。

另外修正按键归一化：X11 左方向键 `0xff51` 及带修饰位形式不能再按低八位被当作 `Q`，右方向键也不能别名为 `S`；Qt/X11 Esc 和普通操作键继续支持。此项与偶发界面等待是两个问题，不能据此宣称 X11 长等待已经修复。

新增诊断字段：`race.csv` 的 `geometry_split_rows`、`red_cap_components`，以及 `display-timing.csv` 的 `time_s`。取证继续保存原始图像和原始二值图，并另外记录颜色过滤后的分叉行数及过滤组件数，便于复核。

## 回来后的第一轮实验

1. 在普通直道上保持摄像头位置固定，无牌观察约 10 秒。
2. 将限速牌自然从画面顶部移入，停留约 2 秒，拿走后观察约 2 秒。
3. 将解除限速牌移入，停留约 2 秒，再拿走；整组重复 3 次。无需刻意避开牌面被顶部截断的瞬间。
4. 预期状态为 `LANE → LIMIT_ZONE → LANE`，限速牌拿走后仍保持限速，解除牌确认后恢复巡航，不应再因相同红色顶部圆弧产生 `FORK_WAIT`。
5. 在图像窗口按 Esc 或 q 退出；图像界面卡顿时可切到终端按 Ctrl+C 请求停止。看到 `[Exit]` / `[Stop]` 并返回提示符后，保留整轮日志供读取。

本轮不驱动车轮，也不要求实验室提供真正岔路。若再次出现误判，只需保留日志和当时图像，不用反复调整摆牌方法掩盖问题。
