# 10 月 23 日：新版普通赛道连续巡线

本轮目的：在目前实验室的普通直道、弯道上验证加入 AI 后的新程序能否连续巡线，并确认主动停车。真实岔路暂不测；先不摆任何路牌，不重复已完成的静态路牌测试。

## 已准备的文件

上传两个文件到小车 `/root/track-trial-20261010/bin`：

- `trackview_race_continuous_20261023`
- `run_lane_compare_20261023.sh`

新程序与昨天两秒版的二进制内容完全一致，只使用新文件名便于区分；连续入口没有传 `--trial-seconds`，因此没有两秒定时退出。程序自身的启动横幅仍写 `timedtrial 2026-10-22`，属于同一份程序的版本名，不表示本轮启用了定时器。

保留车上现有 `trackview.json`、`race.json`、`librace_npu_backend.so`、模型和标定文件。脚本从现场的 `trackview.json` 生成独立副本，仅将 `cruiseSpeed/maxSpeed/curveSpeed/degradedSpeed` 四项设为 0.10 m/s；巡线增益、图像裁剪等其他设置沿用现场文件。原 v6 和新版均能通过本脚本使用相同参数。

上次在 v6 中按键临时调到的速度不作为本轮默认值。0.10 m/s 是指令设置，并非已经测量的实际车速。

## 下午先做这一轮

1. 将车放在普通赛道直道中央，路面没有路牌和杂物。关闭其他正在运行的车辆程序，人在车旁保留断电手段；已有远程图像按键延迟，不能把键盘当作无延迟停车装置。
2. 在 MobaXterm 小车终端执行：

```bash
cd /root/track-trial-20261010/bin
chmod +x ./trackview_race_continuous_20261023
bash ./run_lane_compare_20261023.sh race drive
```

3. 默认 `MANUAL`，不会自动开始巡线。点击图像窗口，松开手柄油门，按一次 `a`。先观察短直道，确认正常后继续经过弯道，争取完整一圈。不要在本轮按 `+/-`、`[/]`、`,/.` 调速，也不用按 `s` 保存样本。
4. 正常结束时，点击图像窗口按空格，确认车停下；再点击终端按 `Ctrl+C` 退出。截图保留末尾 `[Log]`、`[Race]` 和 `[Stop]` 信息。

请记录四件事：是否完成一圈；是否在直道/弯道明显偏离；是否无牌却自行停下；空格后是否停下、是否有明显延迟。如果自行停止或出现 `FORK_WAIT`、`SIGNAL_WAIT` 等状态，先保留状态和图像，不反复按 `a`；提前断电时也说明断电原因。

## 什么时候需要再跑 v6

如果新版这轮表现正常，不要求马上重复 v6。如果新版偏离、停顿或丢线，用同样的位置和赛道执行以下命令做对照：

```bash
bash ./run_lane_compare_20261023.sh v6 drive
```

同样按 `a` 开始、空格停车，再用终端 `Ctrl+C` 退出。脚本仅识别 `trackview_fixed_v6_max10_defaults` 或 `trackview_fixed_v6_max10_default`；若两者内容不同，会要求先核对版本。

脚本默认 `preview`，例如 `bash ./run_lane_compare_20261023.sh race` 只计算决策、不驱动车轮。实跑必须明确写 `drive`。

## 日志及后续

每次启动保存 `lane-compare-records/<时间>-<PID>-<race或v6>.json` 及 `-launch.json`。新版另保存 `-race.json`，冻结本次比赛策略。程序详细日志仍在 `trackview_logs/<毫秒时间>-<PID>`；通过 PID 与启动记录对应。

下午运行结束后，提供终端截图和现场现象即可继续分析。我会回收完整日志，检查巡线周期、AI 结果时效、意外停车原因和速度/转向指令。若新版普通赛道通过，再在有准备的条件下安排行驶中停车/放行、限速响应；完整岔路和另一辆车的标定核对留到具备赛道条件时做。

## 离线验证的边界

1,000 帧合成直道和 100 帧已有相机录像，两版在相同低速配置下的中心位置、速度指令、舵机 PWM、AUTO 状态与丢线状态逐帧一致；新版只有 `LANE` 状态，完整处理 1,000 帧，未启用定时器。启动脚本的 3 项边界测试通过。

回放使用记录的识别结果，不运行真实摄像头、AI NPU 或串口，不能据此判定实车帧率、停车距离或真实弯道效果。远程界面延迟尚未被证明解决；真实岔路尚未实测。
