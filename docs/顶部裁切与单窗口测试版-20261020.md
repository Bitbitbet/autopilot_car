# 顶部裁切与单窗口测试版（2026-10-20）

独立程序名 `trackview_race_cropui`，静态脚本交付名 `run_race_static_test_v2.sh`。保留现有 `trackview_race_topology`、旧脚本、用户 JSON 及 NPU 插件。本版已完成离线回归和 ARM64 交叉编译，尚未部署或在 T710 实测。

## 现场证据与修复

两轮现场日志分别是 `1792475658486-13101` 第 462 帧、`1792482459384-641` 第 662 帧。前者在牌面向上移出时误报，后者的相邻帧显示牌面从顶部进入；两者都处于牌面部分裁切、AI 尚无有效目标的过渡。不能只用“延续旧牌框”或“仅处理抽离动作”的办法解决。

旧版分叉几何检查止于 `rowCutUp=10`。这两帧在第 11 行至下方仍呈现单个黑色分隔带，但第 0～9 行已经能看到圆环内部的白色，黑色分隔带因此分成两条圆环边。裁掉顶部十行后，这个关键证据被忽略了。

`raceBranchPath` 继续使用原搜索区累计分叉行和输出路径，仅将搜索区上方直到图像第 0 行的像素用于分隔带连续性复核。顶部出现白色内部或分隔带组数变化，原候选不再成立。顶部复核点不进入 v6 转向路径，也没有增加延时确认、降低 AI 置信度或沿用失效牌框。

## 界面和退出调整

- 默认只有一个 `track_view` 窗口：左侧是当前巡线图，右侧是与推理结果匹配的 AI 原帧。按 `v` 切换右侧 AI/二值图，按 `s` 的样本仍来自当前显示的 AI 快照。
- 默认显示刷新为 5 FPS，控制与推理循环不跟随降频。单窗口 640×300 图像，比之前三窗口合计的传输像素少；实际网络和 Qt 后端的改善需现场测量。
- `Esc` 和 `q/Q` 都可退出。改用保留完整键值的 `waitKeyEx`，显式兼容 Qt 的 Escape 常量后再处理普通按键；避免直接取低八位把该常量变成 0。收到退出键后先请求停车，再写诊断、等待退出；输出 `[Exit] Quit key received; control stop requested, saving diagnostics...`，便于区分没收到键和已在保存。
- 空格的停车请求优先于诊断写盘。显示日志不再每次轮询都强制刷新磁盘，仍在画面刷新或收到按键时刷新；增加 `render_ms`、`wait_key_ms`、未截断的 `raw_key`，便于区分绘图、事件等待和键值兼容问题。旧日志中的两个 0 键值没有保存原始码，不能仅凭它们确认现场根因。
- 终端 `Ctrl+C` 继续是独立的退出请求途径。程序无法记录没有送到图像窗口的按键，所以不能保证解决所有焦点或无线问题。
- 可选 `--display-fps 1..10` 调整显示刷新；`--legacy-windows` 保留原三窗口布局供对照。普通静态脚本使用默认单窗口。

### 保留的能力限制

33 个刻意构造的边界案例中，14 个与预设相符、18 个分叉边界未识别、1 个同像案例无法单凭几何区分。新增的一个排除案例是分隔带在第 11 行结束、画面顶部已经合流：旧规则忽略了合流部分，新规则将其视为有限分隔带。

这仍是严格的图像连续性规则，不具备完整的有限分隔岛、窄支路、遮挡和合流处理能力。实际场地没有岔路，不能宣称本版已经通过真实岔路行驶验收。圆环内部完全超出画面的其他裁切形态也可能与道路分隔带同像，需要继续保留正常拿放牌的现场测试。

## 现在需要的现场测试

只上传包中的两个文件到自己的 `/root/track-trial-20261010/bin`，不用替换插件或 JSON：

```bash
cd /root/track-trial-20261010/bin
chmod +x ./trackview_race_cropui
bash ./run_race_static_test_v2.sh limit
```

终端应显示 `trackview_race cropui 2026-10-20 | NO CONTROL`，图像应变成单窗口。点击该窗口，按一次 `a`：

1. 无牌观察 5 秒。
2. 正常放入限速牌约 3 秒，再正常拿走约 3 秒。
3. 正常放入解除限速牌约 3 秒，再拿走约 3 秒。
4. 重复第 2、3 步三轮，正常拿入/抽离即可，不需要支架，也不用刻意回避移动过程。
5. 最后点击同一个窗口，按一次 Esc，观察是否出现 `[Exit]` 提示，以及到最终 `[Stop]` 的大致等待时间；若图像窗口没响应，可在终端按 Ctrl+C。

本轮全部为 `--no-control`，不驱动车轮。完成后发终端最后几行和 `[Log]` 目录名；若仍出现 `FORK_WAIT`，保持约两秒让自动取证收集后续帧，再退出。速度由日志核对，不用一边拿牌一边盯速度。
