# 障碍绕行公开代码调研

检索日期：2026-10-29。本轮仅查看作者仓库、源码和文档，没有下载或引入第三方实现，也没有修改当前绕行算法。下述适用性判断基于接口和代码阅读，未在本车运行。

## 优先参考：PythonRobotics 的 Frenet 规划

- 仓库：[AtsushiSakai/PythonRobotics](https://github.com/AtsushiSakai/PythonRobotics)。
- 已阅读源码：[frenet_optimal_trajectory.py](https://github.com/AtsushiSakai/PythonRobotics/blob/master/PathPlanning/FrenetOptimalTrajectory/frenet_optimal_trajectory.py)。
- 许可证：[MIT](https://github.com/AtsushiSakai/PythonRobotics/blob/master/LICENSE)。

它沿参考路径生成多条横向/纵向候选轨迹，按代价选择，过滤速度、加速度、曲率和障碍碰撞。最值得借鉴的是候选轨迹筛选、曲率约束和绕过后回到参考线的处理。

它接收米制障碍坐标和车辆状态，不负责摄像头识别或视觉里程计。示例用圆形碰撞半径，默认车速、路宽和预测尺度远大于本车，不能直接沿用；我们的长车身和车尾净空仍要单独检查。示例主循环在无新路径时会复用上一条路径，也不能把这种仿真处理直接作为本车放行条件。它有助于研究路径质量，无法直接解决现有特征不足、运动估计失效或地面距离不准。

## 摄像头锥桶案例：VisionCar

- 仓库：[Sering-Hong/VisionCar](https://github.com/Sering-Hong/VisionCar)。
- 已阅读源码：[vision/line_follower.py](https://github.com/Sering-Hong/VisionCar/blob/main/vision/line_follower.py)。
- README 标注 MIT；平台是 RDK X5 + STM32，双轮差速驱动。

实现 HSV 红色锥桶分割、形态学、轮廓筛选、巡线平滑和避障状态机，适合参考锥桶底部定位与检测稳定性。其避障主要是定时的停、后退、右转、前进、左转、前进序列；本车为前轮转向，不能照搬差速转向动作，也不能靠固定时间推断车尾已经通过。当前公开 Python 源码在 `@property` 与 `avoid_sequence` 附近还可见缩进异常，未做运行验证，不能视作现成可用程序。

## 通道选择案例：F1Tenth Follow the Gap

- 仓库：[RhythmChandak/F1Tenth-follow-the-gap](https://github.com/RhythmChandak/F1Tenth-follow-the-gap)。
- 已阅读源码：[gap_follow/scripts/reactive_node.py](https://github.com/RhythmChandak/F1Tenth-follow-the-gap/blob/main/gap_follow/scripts/reactive_node.py)。
- README 标注 MIT；ROS 2，输入 `/scan` 的 LaserScan，输出 AckermannDriveStamped。

它给近障碍加排除区，扩展距离突变，再寻找较深的可通行间隙并计算转角。可借鉴膨胀障碍、按车宽筛选通道的思路。它依赖激光雷达距离，不能将相机像素直接当作扫描距离。

代码里某些间隙宽度条件只有 `0.8 * car_width`，无有效间隙时还有回正继续计算速度的分支；因此这里只作为算法思路参考，不建议直接移植。其原始速度和尺寸也不适合 45 cm 窄赛道。

## 完整赛车系统：ForzaETH Race Stack

- 仓库：[ForzaETH/race_stack](https://github.com/ForzaETH/race_stack)。
- 已阅读模块说明：[spline_planner](https://github.com/ForzaETH/race_stack/tree/ros2-humble/planner/local_planners/spline_planner)。

局部规划器订阅障碍、Frenet 车辆位姿和全局路径，输出绕障样条路径；参数明确包含道路边界最小距离、障碍前后的样条控制距离。适合参考“绕出、经过、回归”的路径组织方式。

整套系统需要感知、定位和路径输入，迁移成本高。仓库说明当前 ROS 2 分支比 ROS 1 测试少，论文结果来自 ROS 1；该局部模块 README 的许可证栏仍为 TODO。这里仅完成架构和模块文档核查，未完整审计其实现或第三方许可。

## 另一个竞赛视觉候选

[巡光小队 xunguang-rdk-x5-medical-robot](https://github.com/ZHUI-MO/xunguang-rdk-x5-medical-robot) 的作者说明包含 YOLO 巡线与锥桶避障，避障利用目标纵向位置、横向偏移和前一次转向；平台为 RDK X5、OriginCar、ROS 2。它还使用编码器、IMU/EKF 支持导航。本轮仅核查作者 README，未完整检查避障源文件和许可，先列为待深入阅读的公开竞赛工程，不作为已经确认可复用的开源实现。

## 对本车的取舍

优先研究 PythonRobotics 的轨迹候选与曲率检查，以及 VisionCar 的锥桶图像特征；Follow the Gap 只借鉴净通道的表达；ForzaETH 留作完整闭环架构参考。

当前最有价值的现场数据仍是锥桶实际净通道、运动估计在接近和并行阶段是否连续、前轮角/PWM 关系和车尾通过证据。外部规划器不能替代这些输入。下午先用同一主程序分项实跑，拿到失败关键帧后再决定需要改感知、路径、运动估计还是转向映射。
