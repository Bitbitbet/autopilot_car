# 落地两秒低速试跑（2026-10-22）

用户无法架空车辆，已确认可以准备至少约一米的普通直道、清走路牌杂物，并安排人在车旁切断电源。因此改为一次性落地短测。该包保留原组员工程和原 `trackview.json`，不覆盖现有 v6、appearance、race 等可执行文件。

## 本版行为

- 独立文件 `trackview_race_timedtrial`，启动标记为 `timedtrial 2026-10-22`。
- 使用独立配置 `trackview_low_speed_20261022.json`：巡航、最高、弯道、降级四个速度参数均为 0.10 m/s。这里是指令值，不是实测轮速。
- 必须使用 `--trial-seconds 2`；脚本固定该参数。程序同时拒绝超过 0.10 m/s 的短测配置。
- 默认手动等待，不因启动程序而自动行驶。本短测模式禁用手动油门输出；接受自动模式后才会启动计时。
- 第一次接受自动启动时启动一次性计时；重复切换不会重置截止时间。
- 独立线程在约两秒后请求零速、锁定停车并请求结束程序，计时不依赖图形界面或相机循环。原有指令超时保护也保留。
- 自动停车后必须重启程序才能再试。空格、Ctrl+C 和车旁断电仍可提前结束测试。

独立线程发出停车请求，不等于已经验证了下位机执行效果或物理停车距离。线程调度、串口写入和车辆惯性会影响实际时间。`trial-stop.json` 记录计时是否启动/到期，以及零速串口 API 是否完成；它不是轮速实测证明。

## 上传

将包内三个运行文件上传至 `/root/track-trial-20261010/bin`：

```text
trackview_race_timedtrial
trackview_low_speed_20261022.json
run_ground_trial_20261022.sh
```

原有 `race.json`、模型、标定和 `librace_npu_backend.so` 继续使用。接入库与上一版字节一致，本包不要求重新上传模型或系统库。

## 本轮实际试跑

车放在直道中央，车头对正，前方清空；车旁人员准备立即切断电源。首次只做一轮，不摆路牌，也不测试弯道或真实岔路。

```bash
cd /root/track-trial-20261010/bin
chmod +x ./trackview_race_timedtrial
bash ./run_ground_trial_20261022.sh drive
```

`drive` 是真实车轮控制模式。确认显示 `MANUAL START`、`[Trial] ONE SHOT`、速度上限 0.1；默认 MANUAL 时车轮应静止。

准备好后，点击图像窗口，只按一次 `a`。接受自动启动后会显示 `[Trial] Timer armed.`，约两秒后应打印 `[Trial] Timed stop requested...`，随后结束。观察车辆是否前进、转向是否异常，以及是否自动停住。

若明显偏向、异常加速或没有停住，车旁人员立即断电，不依赖卡顿中的图像窗口。不自动重试，也不连按 `+` 加速。

如果显示 `[Wait]` 而没有 `Timer armed`，表示赛道或 AI 尚未满足自动启动条件；车应保持静止，保留提示信息供检查。

默认不带模式或显式 `preview` 时，脚本使用 `NO CONTROL`：

```bash
bash ./run_ground_trial_20261022.sh preview
```

## 记录与验证

配置副本、启动模式、程序/配置哈希保存在 `low-speed-trial-records`；相机和控制日志仍在 `trackview_logs`。提供本轮程序输出或实验目录名后可读取数据，原配置不改写。

本地验证包括：等待首次启动才计时、一次性截止时间不重置、普通模式不受影响、速度参数拒绝、调用方阻塞时模拟串口仍被锁定、原串口和界面阻塞回归、14 帧红色顶部样本、任务状态机、普通入口回放和完整定时退出回放。回放与模拟设备不替代本轮实车验证。

图形界面偶发长等待本身尚未解决。本版增加独立停车截止时间，不宣称已经消除网络或图形后端卡顿。
