# 智能小车：固定程序与验证入口

主程序固定为 `trackview_race`，统一入口为 `run_car.sh`。后续改进继续更新这两个入口及配套 AI 适配库，不再通过更换日期版程序进行日常测试。

## 本次变更

停车牌：保留模型真实分数。普通检测仍使用原配置的 `confidence`（目前0.65）；仅对 `stop` 采集0.35以上低分候选，并用同一推理原图检查红色区域、中央白横杠和上下红色区域。通过后仍需连续3次新观测、未过期，以及原来的接近位置条件，才能触发对应任务。关闭 `verifyStopCandidates` 可以恢复单一阈值行为。

绿牌、岔路、限速及其他类别继续使用原阈值。绿牌仍需连续确认，低分停车牌复核不能用于放行。拿走红牌不能取消已进入的等待状态。

右侧匹配AI画面会保留真实分数，低分且通过图形复核时标注 `CHECKED`；未通过时标注 `REJECT`。单帧 `CHECKED` 不表示车辆一定已停车，仍需查看终端比赛状态及现场车辆。

## 安装与原有资源

交付包中的以下4个运行文件放入车上现有 `/root/track-trial-20261010/bin`：

- `trackview_race`
- `librace_npu_backend.so`
- `run_car.sh`
- `release-manifest.json`

安装前退出旧程序。主程序与适配库必须一起更新，清单会核对两个文件的SHA-256，不能混用旧库。旧的日期版比赛程序不作为本次入口，v6巡线备份仍保留。

继续使用该车原有 `trackview.json`、`race.json`、`../res/models` 和 `../res/calibration`。不要用交付包替换组员工程、原模型、标定或下位机固件。另一辆同型号车仍需核对自己的相机标定、舵机方向与中位等参数。

## 固定命令

```bash
cd /root/track-trial-20261010/bin
chmod +x ./trackview_race
bash ./run_car.sh preview signal
```

这是下一轮优先使用的命令，不驱动车轮：

1. 放在当前实验室平整赛道，确认图像与AI正常。识别不需要按 `a`；要计算 `LANE/SIGNAL_WAIT` 等比赛状态，再在图像窗口按一次 `a`。
2. 依次检查空路面、白纸、绿牌没有被补认成stop；红牌靠侧边和完整入镜时能显示真实分数及必要的 `CHECKED` 标记。
3. 红牌足够接近时应进入 `SIGNAL_WAIT`，拿走后仍等待，确认绿牌后恢复 `LANE`。接近阈值依旧为框底边达到配置中的 `triggerRow`（目前145/240行），不能用肉眼百分比代替。
4. 在出现问题的画面按 `s` 保存匹配图像与接受原因；用 `q/Esc` 或终端 `Ctrl+C` 退出。

预览验证后再安排实跑，固定命令只需换一个模式：

```bash
bash ./run_car.sh drive signal
```

`drive` 会真实控制车轮，默认MANUAL，按 `a` 才自动巡线；图像窗口空格停车，终端Ctrl+C退出。测试选平整直道、牌面不阻挡行驶道路，车旁保留断电手段；远程GUI仍可能卡顿，不能承诺按键即时响应。绿牌确认后会自动恢复行驶，展示前先留出空间。

其他场景同样通过固定入口选择：

| 场景参数 | 用途 |
|---|---|
| `lane` | 普通赛道连续巡线，比赛规则沿用原race配置 |
| `signal` | 独立停车/放行测试，配置副本关闭先过斑马线条件 |
| `limit` | 限速/解除限速，副本限速设为0.08 m/s（不低于该车minSpeed） |
| `competition` | 沿用原比赛任务规则，初始速度仍为0.10 m/s，并非已验收的比赛配置 |

所有场景启动时的巡航、弯道和降级速度仍为0.10 m/s；最高可调上限已按用户要求于2026-10-24恢复为10 m/s。图像窗口中的 `+`/`=` 与 `-` 调巡航，`]`/`[` 调弯道，`.`/`,` 调降级速度，每次0.05 m/s；重启后回到初始值。10是程序允许调整的上限，不是启动速度或已验证的实车速度。任务和道路质量仍会限制实际速度指令；没有两秒定时退出。脚本从现场配置创建运行副本，保留其他巡线参数，原配置不改写。不带参数默认为 `preview lane`。

## 数据与验证边界

运行副本和启动清单保存在 `run-records/<时间>-<PID>-<场景>`，详细日志仍在 `trackview_logs/<毫秒时间>-<PID>`。`detections.jsonl` 保留原始分数，并追加是否接受、是否图形复核、接受/拒绝原因。

截至2026-10-24，已完成本地整合和离线回归，并在原实验室T710上完成多次0.10 m/s红牌停车、绿牌恢复实跑。现场人员观察到实际启停，两轮日志均记录了红牌触发等待、等待期间零速度指令及绿牌确认后恢复。日志指令不是独立实测车速，尚无停车距离测量。最高可调上限恢复为10后的更高速度未验证；真实岔路、坡面通行和另一辆车的标定核对仍待现场条件。施工与泊车专项规划仍未完成，不能视为比赛全部任务通过。
