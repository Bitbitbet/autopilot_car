## 直接测试停车完成情况（无手柄）

无需手柄或先拍轮角照片即可进行本轮停车测试。仍用下文的 parking-drive competition black，保持启动零速、初始巡航0.10和最高可调10。此轮不添加原地打舵、试转弯或后退找位动作。出现黄色车位、绿色路线后按a，空格停，故障后g重新识别。p在自动路线就绪时会提示按a，不再要求手动冻结。

窗口 PLAN / IN / 3S / OUT 分别表示路线生成、控制器确认整车入位、确认连续停稳3秒、确认倒车回通道；未达到显示“--”。这些标记来自本轮实时控制器与视觉里程，不是独立外部测量，路线模型通过也不等于实车通过。按a条件不满足时终端显示具体阻止原因。

每次运行的 parking-test-summary.json 保存最多最近32轮g/r重试的分项结果、原始故障原因、驱动指令帧数和转向等待帧数；完整逐帧记录仍在 parking-control.jsonl。中途失败、退出或重试不累计成成功；只有实际控制进入 PARK_COMPLETE 才记录本轮停车动作完成，是否已恢复巡线另记一项。入口左转、停车牌触发与出口箭头转弯仍不包含在此测试范围。

当前轮角仍为实验值，可通过本轮直接测试继续收集跟随差异；轮角照片/量测作为后续改进数据，不是启动本轮测试的前置条件。

## 运行

上传同目录的 trackview_race、run_car.sh、release-manifest.json。AI适配库本轮未变化。保留车辆配置、模型和 ground-calibration.json，不使用旧ZIP。

```bash
cd /root/track-trial-20261010/bin
chmod +x ./trackview_race
bash ./run_car.sh parking-drive competition black
```

车头沿中央通道朝出口，默认零速。程序连续三次看到稳定的白线T形结构、检查已知车位尺寸，然后尝试前进入库规划；黄色是选中车位，绿色是路线。近处端头被画面截掉时不猜位置，可选择前方完整可见的左侧车位。看到黄线与实际车位一致、绿线正确进入车位，再按a执行。

- a：执行已生成的路线。没有鲜活可执行路线时不运动。
- g：停车状态下重新自动识别和规划。
- 空格：立即停止；中断后不自动续跑。
- q/Esc/Ctrl+C：退出。
- f：转为手动冻结点选诊断；先点近、再点远，p规划；r清除手动记录。日常自动定位不需要f、鼠标或p。
- 静止时s：保存原图。

启动巡航仍为0.10，最高可调10；狭窄车位内前进上限0.10、倒车0.08属于停车任务限制。出库后恢复原v6巡线和道路质量/弯道限制。

候选路线还会先通过当前控制器的理想运动学检查；若当前曲率采样的路线预计无法连续跟随，会在原转向上限内尝试其他前进曲线，仍失败就不接管。模型通过不是实际轮角标定或实车验收。

## 后面有道闸时

不要求倒退来满足旧的“近端至少8cm”。这个数值是旧实现的起步条件，不是实测转弯或刹车极限；现已取消。可见点的顺序、尺度、朝向和全车身路径仍须通过检查。

规划从当前位置只向前入库，车身扫掠不能比起始时已占用的车尾后沿更靠后。倒车出库返回起始位置附近，同样不能越过这个后沿。这个几何边界不是后方传感器：它不能识别移动的道闸、测量闸与车尾的真实距离，也不能替代尚未标定的轮角响应。没有可行路线时保持停车，不命令向后找起点。

近处车位找不到前进入库路径时，自动尝试当前画面内其他完整可见的左侧车位；无法确认就等待。当前仅按用户指定的全空场景工作，不会绕过人、锥桶、红牌或道闸的停车义务。

## 几何和控制边界

实测尺寸：中央通道45cm，车位四边41cm、垂直进深38cm、前后错位约15.4cm；车宽18cm、车长31cm、轴距20cm。入口伸出的短白线可以压，算法不把这些像素当障碍墙。当前按完整车身加5mm余量规划，终点无附加余量；短程转向预测冲突作为提示，起始车尾边界保留。

车位定位来自实时白色T形标线几何和当前车辆的地面映射，不复用上次点选的旧坐标。满舵45度、车头至后轴25.5cm仍为实验初值，未实测标定。位姿来自地面纹理运动，不以速度乘时间冒充位移，不在视觉失效时假定零运动重锚。

入库接近终点且完整车身已经包含在车位内时开始停车，不为匹配一个理想终点继续逼近边线。倒车按新鲜视觉记录的实际入库轨迹返回，记录在 parking-reverse-route.json；完整车身回通道、姿态沿通道且接近起点时结束倒车，不继续向道闸追逐一个精确坐标。规划/预测后沿与视觉有效性检查保留，观测后沿有上文说明的2mm误差预算。

动作依次为 PARK_ENTRY、PARK_DWELL、PARK_EXIT、PARK_COMPLETE、PARK_REJOIN_WAIT/PARK_REJOIN_LANE。完整车身在位且连续新鲜图像确认近乎静止后，才累计停稳3秒；视觉/车身/交通条件不满足就停车。每阶段45秒预算、独立250ms串口指令超时和原有交通任务保持。

## 记录与验证

日志仍在 trackview_logs/parking-<毫秒时间>/。parking-route.json 记录 selection_source、是否识别车位数字、起始后沿边界和实际采用的车位坐标；自动选择时bay为空，不伪称认出了1号或2号数字。parking-teaching-attempt.json/png 保留定位和搜索原因。parking-control.jsonl、parking-result.json 保留真实故障原因、视觉拟合指标；首次移动后停车还会异步保存最多12帧原图到 parking-stop-evidence-*。

离线检查包括：可见近点不再被8cm条件拒绝；起始车尾边界；前进入库、停3秒、倒车出库的理想闭环；两张已保存实车原图的车位口定位与前进路径、纯黑/纯白反例及启动器检查。这些是开发样本和模拟，不是独立识别准确率或实车成功证明。

此前两轮实际停止原因分别是右侧车身预计越界、地面刚体运动拟合失败，并非入口白线不允许压。本轮结合现场数据按用户要求减少附加余量、把预测越界改为继续提示，保留日志供后续核对实车路线与模型的差异。
