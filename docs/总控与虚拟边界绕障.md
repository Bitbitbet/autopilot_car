# 完整任务的当前入口

当前已统一为master原生640×480任务链路，详细流程、代码位置、出口地面箭头的阶段限制和回退方法见[合并检查与线程说明](合并检查与线程说明.md)。

完整比赛：`bash ./run_car.sh mission competition black`；无电机预览：`mission-preview`；实验室单环：`mission-lab competition white`。独立停车用`parking-drive`，独立虚拟绕障用`bypass-virtual`。初始速度0.10m/s，最高可调10m/s。

地面左箭头只在停车完成且倒回通道后的停车场出口阶段触发主动左转寻路，第二圈无此触发；终点仍按n确认。所有模式在同一任务实现上通过参数切换。
